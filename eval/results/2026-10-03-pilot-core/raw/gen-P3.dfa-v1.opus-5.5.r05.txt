Walking skeleton (Phase 0)\n**The one real request:** a real code change to **one real, stateless, low-criticality service** (e.g. an internal lookup API) is merged to `main` and reaches prod. A real call to the service's endpoint then returns the new version's real response.\n\n**Tiers crossed:**\n1. **Source:** a merge to `main` in a GitHub repo with branch protection.\n2. **CI:** GitHub Actions on an **ephemeral** ARC runner.
