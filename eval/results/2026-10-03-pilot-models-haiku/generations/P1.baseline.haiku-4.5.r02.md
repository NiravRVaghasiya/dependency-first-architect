### **Phase 2: Data Ingestion & Indexing**
- **Chunking Strategy**
  - Split docs into semantic chunks (500-1000 tokens)
  - Preserve context with overlapping sections
  - Maintain metadata (source, category, section, timestamp)

- **Vector Embedding**
  - Use embedding model (e.g., OpenAI's text-embedding-3, Anthropic Claude embeddings)
  - Store in vector database (Pinecone, Weaviate, Chroma, Milvus)
  - Index with hybrid search (semantic + keyword)

### **Phase 3: RAG Pipeline**
```
User Query
    ↓
Query Understanding (intent detection, entity extraction)
    ↓
Retrieval (semantic search + ranking)
    ↓
Context Selection (top 3-5 most relevant chunks)
    ↓
Prompt Engineering (system prompt + retrieved context + user query)
    ↓
LLM Generation (Claude for high-quality responses)
    ↓
Post-Processing (source attribution, confidence scoring)
    ↓
User Response
```
