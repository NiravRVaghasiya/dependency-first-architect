Walking Skeleton (Phase 0)\n\n**Real request path:**  \n1. GitHub issue opened or reopened → webhook fires → agent receives JSON payload (issue title, body, labels, author, URL).  \n2. Agent reads issue text → calls inference endpoint (Claude 3.5 Sonnet) with prompt: \"Classify this GitHub issue into: bug, feature-request, documentation, question, duplicate, spam, invalid, wontfix. Respond with JSON: {category, confidence, reason}.\"  \n3. Agent applies label(s) based on category (e.g., \"type: bug\"); posts comment: \"Triage: classified as [category] (confidence [%]); [reason]. Assigned to [team] for review.\" (or escalates if confidence <70%).  \n4. Response logged to stdout as JSON event: {timestamp, issue_id, category, confidence, labels_applied, tokens_used, cost_usd, latency_sec}.  \n5. Deployed: agent runs as a GitHub App with webhook receiver on HTTP endpoint (localhost:8000 for Phase 0; behind firewall or ngrok tunnel).  \n6. Rolled back: disable webhook, labels/comments remain (safe), revert code in-place.  \n\n**Who can reach it:**  \n- Phase 0: **Internal testing only** – one private test repository, add 2–3 test issues manually (not from external users). Webhook allowlisted to internal IP or ngrok authtok.  \n\n**Why it is read-only / scaffolded:**  \n- Agent does NOT close, reassign, or delete issues in Phase 0 (read-only on mutations).  \n- Inference endpoint is on a test API key with $5 daily cap + 1,000 req/day rate limit (prevent runaway cost if bug loops).  \n- Token cap 1,000 output per issue (hard stop).  \n\n**Exit check V0:**  \nOne real issue flows end-to-end:  \n- ✓ Webhook fires, payload reaches agent  \n- ✓ Agent classifies issue and posts a label + comment  \n- ✓ Log entry appears in stdout with cost/latency/confidence recorded  \n- ✓ No prompt-injection test issue succeeds (agent refuses and escalates)  \n- ✓ Deploy succeeds via GitHub Actions; rollback (disable webhook, revert code) succeeds within 5 min  \n- ✓ Injected failure (kill inference endpoint) is visible in logs within 10 sec; alert fires  \n- ✓ Baseline metrics recorded: 0-load latency (first issue, cold inference): ~2–3 sec; cost per issue: $0.01–$0.03  \n\n---\n\n## 5.
